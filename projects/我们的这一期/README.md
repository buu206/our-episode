# 在场 · 开发运行说明

产品介绍、演示启动和开源状态见[仓库首页](../../README.md)。目录保留历史名字，产品现在显示为「在场」。

## 无密钥演示

在产品目录中运行 `bash scripts/run-demo.sh`，另一个终端运行 `bash scripts/run-web.sh demo`。网页 http://127.0.0.1:3001，公开本机演示登录码 `demo`。需要先按仓库首页安装后端/前端依赖与FFmpeg。演示模式不读真实模型配置，固定结果不能当作真实AI能力。

## 普通本机服务

在产品目录运行 `backend/.venv/bin/python scripts/setup-local.py`，只在不存在时创建私有 `backend/.env` 和随机邀请码，不覆盖已有配置、不显示邀请码。按 `.env.example` 添加所需的服务端模型配置，保留原会话设置。模型默认关闭，使用前须核对服务条款与授权范围，真实付费请求受预算约束。

分别运行 `bash scripts/run.sh` 和 `bash scripts/run-web.sh normal`。网页为 http://127.0.0.1:3000，后端监听127.0.0.1:8788。邀请码由本机管理员从自己的 `.env` 读取，不写进仓库。

代码修改后在 `frontend/` 执行 `npm run build` 并重启网页；运行脚本会使用独立构建副本，避免构建时破坏正在打开的静态资源。

## 数据与恢复

正常数据在 `data/`，演示数据在 `data/demo/`，均不提交Git。任务、版本、确认点和预算持久化。应用副本按整期30天保留并支持主动删除，修改和重生成不延长期限；不删除外部原视频，供应商副本的留存需另行核实。

新选定拍法的本机委托可暂停、继续、结束，最多一次本机中断重试，最终停在未确认候选。字幕与选段检查是时间/文字规则，抽样画面检查未听声音；都不能代替人工内容判断。

## 测试

后端：在 `backend/` 运行 `.venv/bin/python -m pytest -q`。前端：在 `frontend/` 运行 `npm test`、`npm run typecheck`、`npm run lint`、`npm run build`。隔离测试使用合成媒体和测试适配器，不读真实私有素材。

历史 `kit.sh` / `verify.sh` 用于本地开发证据管理。公开仓库不带私有授权、当前真人截图及模型调用账本，因此不能把缺少私有证据的阶段闸门当作开源安装失败，也不能手工补造冒烟记录。

## 已知限制

完整连续视听语义和模型自主内容返工尚未完成；综艺观感仍需样片评测。MediaPipe可选CPU适配器已在Mac验证，Linux实机效果尚待验证。当前没有公共后端或在线Demo地址。需要公开部署时，必须另做生产配置、数据隔离、配额与媒体存储验证，不能直接将本机演示服务暴露到互联网。
