## 2. 中文粗黑标题子集

前期在系统/用户字体目录、已有frontend依赖、已有Codex技能与插件资源中未找到可直接分发的中文粗黑字体。系统Python、Homebrew Python和后端venv没有fontTools/Brotli Python模块，未安装工具、未复制macOS字库。

按后续授权，已从Google Fonts官方CSS的`text`参数接口获取900字重成品小子集，下载到本地使用；没有下载全量字体。官方基础字体与字重依据：[字体目录](https://github.com/google/fonts/tree/main/ofl/notosanssc)、[字重100–900的元数据](https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/METADATA.pb)。

| 页面本地地址 | `/home/fonts/episode-title.woff2` |
| 大小与格式 | 4,772字节；文件签名`wOF2`，与官方CSS的`format('woff2')`一致 |
