# 首页定稿 · 2026-11-08

当前阶段：阶段3-1，最新定稿实现与验证中。本文记录视觉与交互目标，不代表最终工程检查、用户验收或真实AI验证已经通过。

## 定稿依据与优先级

用户本次在对话中提供的 **1440×900 首页截图及随附 brief** 是最新视觉依据，优先于此前的橙黄看板、紫绿互动字贴和简约多行输入方案。原附件目前只在本次对话中，未保存为本地图片文件；本文不声称已归档截图，也不虚构截图路径。

本次重点是桌面首屏的比例、留白和信息层级。保留已支持的手机访问与业务操作，仍需检查窄屏布局，不能以桌面定稿为由删除移动端适配。阶段不变，继续3-1，不提前进入3-2。

## 桌面首屏构成

| 位置 | 定稿要求 |
| --- | --- |
| 整体 | 奶油暖白底，少量粉、黄、薄荷柔光；简洁、有生活综艺的轻松感，不采用黑底霓虹或紫绿大字贴 |
| 浏览器壳 | 页面内绘制三点与圆角地址栏，形成截图中的浏览器壳；这是装饰，不是实际浏览器控件、已部署地址或安全认证。实际本机运行模式仍清楚可见 |
| 顶部左侧 | 渐变底“期”字标，配产品名“我们的这一期” |
| 顶部中央 | “开场 / 往期 / 怎么玩”三级导航；分别到首页、已有节目区和操作说明，不新增未实现页面 |
| 顶部右侧 | “我的账号”，读取当前真实会话并提供已有退出操作；不新增注册、个人资料、计费或独立账号服务 |
| 开场小字 | “第 07 期 · 周五夜场”，作为示例节目场景，不冒充用户真实节目数量或当前日期 |
| 主标题 | “我们的这一期”，前半深色，后半暖粉至珊瑚渐变；粗黑中文标题与充足留白，不写“两分钟出片”等未经验证的时间承诺 |
| 主题贴纸 | 黄色主题贴纸，例如“说好今晚不点外卖”；它是装饰主题示例，不是模型生成结果 |
| 朋友头像 | 五个圆形朋友头像与示意称呼，使用本项目原创生成图片；角色不是已邀请的用户、已授权出镜者或当前参与者列表 |
| 主输入 | 单行胶囊：左侧“✦ AI”，中间主题占位提示，右侧黑色“开拍”按钮配粉色录制圆点；输入有独立可访问名称，不能只靠placeholder说明用途 |
| 占位提示 | “今晚想拍什么？比如：说好不点外卖 / 谁先破功…”；主题仍可编辑，不自动认作视频事实或已确认表达 |
| 输入下方 | 微提示“丢一句主题就行，素材可稍后补”；不使用“照片”来暗示尚不支持的图片上传 |
| 次要入口 | “逛逛往期”文字链接，引向真实已有节目；不以虚构作品填充列表 |
| 首屏以下 | 上传与灵感模板放入默认折叠的“添加素材与更多灵感”，最近制作和操作说明继续保留；精简首屏不等于删除功能 |

配色基线：奶油`#f8f5ef`、正文`#211e1a`、暖粉`#ff6d9e`至珊瑚`#ff9960`渐变、黄`#ffd465`、薄荷`#ddf6ed`。装饰色不承担唯一的错误、状态或焦点提示；控制文字保持清晰。

正文首页不再使用`ShowBackdrop`环绕艺术字贴。旧紫绿字贴方案作为历史保留，登录页暂存的该组件不代表本次首页定稿。开场动画继续使用2.7秒字卡、产品字标和揭幕结构，配色同步奶油、粉黄薄荷及暖珊瑚；跳过、Esc、手动重播、标签页仅首次自动播放和减少动态效果支持保留。不开自动音效。

## 资产与事实边界

头像实际文件是`frontend/public/home/friends.png`，网页使用`/home/friends.png`。这是原创生成的五位虚构成年人图片，来源、示意称呼及生成记录见[本轮资产来源](本轮资产来源.md)。不使用用户私密素材制作首页头像，也不把静态图片称为本产品剪辑或真实AI的效果。

期数、主题、朋友称呼和头像均为装饰示例，应有相应说明，不与真实会话或节目数据混淆。“✦ AI”是产品方向标识，**真实云模型尚未接入当前验收流程**；首页、账号和具体操作须如实区分本机制作与固定结果演示。既有“演示结果非真实AI、提示音非人声旁白”说明不能因简约视觉被隐藏。

## 保留的功能与恢复规则

1. 输入主题或选择受支持的视频后，“开拍”复用创建节目与逐文件上传接口，再进入既有制作流程。仅输入主题也可先创建，素材稍后补；这个按钮不自动分析、生成旁白、渲染、确认或分享。
2. 想法仍作为用户制作意图保存，最多4000字；标题沿用确定性规则，最多120字。改变输入外观不改变后端校验与字段含义。
3. 上传仍支持MP4/MOV，每期最多8份、合计600秒及1GiB，显示真实传输与服务端校验状态。照片、单独音频或第三方URL不因首页文案而成为新增能力。
4. 防重复提交、部分成功保留、失败重试、未知结果先回查、已创建节目继续处理及未保存离开提示均保留。不能为页面更简洁而删除错误恢复入口。
5. “素材→核对与方向→编辑→预览确认”的既有路径、版本隔离、来源权限、人工确认和导出规则保持不变；账号退出继续清理相应会话状态。

## 后续核验

新版冻结后再记录实际结果：1440×900桌面首屏与附件对应关系、375/390px窄屏无横向溢出、导航和真实账号退出、单行输入与折叠上传、部分失败/未知结果恢复、开场跳过与减少动态效果、原制作闭环回归。本文不预填测试数、生产构建、浏览器检查或用户验收结论；最终证据由阶段3-1工程检查和证据包承接。真实AI验证仍按用户安排延至上线前，不能用视觉定稿或固定演示抵扣。
