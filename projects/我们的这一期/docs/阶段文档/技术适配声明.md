# 技术适配声明

基线日期：2026-11-06，进度更新：2026-11-08。阶段0、阶段1已由产品经理明确验收通过；本文保留阶段1技术设计基线，并记录后续子阶段与验收安排调整。阶段2-1、2-2、2-3本机用户验收已通过；当前3-0前端适配文档已交付、待用户审阅，真实AI仍待验。

## 1. 产品形态判断

- 产品类型与核心任务：基于真实聚会视频的多媒体创作产品，让发起人把一次活动做成有依据、可核对、可纠正的综艺短片。
- 核心交互：素材上传→有来源的方向提案→用户选择→生成初版→纠错与预览→确认具体版本→导出；朋友供材、本人语音/视频采访和受控分享分后续批次完成。
- 开发路径：后端先行，阶段2同时提供一次性可视化验收工具，实际操作选方向、看原片和确认导出。暂不将UI做成正式可保留前端，避免核心内容能力未验证就扩展界面。
- 验收界面：`backend/static/` 单页HTML与原生JS，由FastAPI同源服务；**临时验收界面，阶段3整体替换**。阶段2不要求其正式前端构建或移动端适配；最终手机与电脑网页要求保留在阶段3。
- 上线套餐：沿用D9，未来CloudBase免费体验版意向；本轮只在本机运行，不创建云资源。
- 原阶段1范围：确定技术方案、组件采纳、分批与验收条件。当前按第7节进行阶段3-0前端适配；正式前端尚未编码。

## 2. 采用的默认方案

| 方案 | 原因与实施位置 |
| --- | --- |
| Python 3.12、FastAPI、Pydantic、pytest | 适合媒体任务、结构校验及API验证；产品目录下单独虚拟环境和锁定依赖，不改系统Python |
| SQLite、SQLAlchemy、Alembic | 节目、素材、版本、确认、任务、会话与预算存在关联和事务；从首张业务表起保存归属字段。数据访问集中在repository，迁移有版本记录 |
| 本地文件目录 | 原视频副本、预览和输出放产品 `data/`，不把大二进制塞进数据库，不公开静态挂载；源文件不改动 |
| 同源Cookie会话 | 邀请码校验后生成HttpOnly会话；后端逐资源校验，写操作加来源/CSRF校验。邀请码与会话值不输出日志，不写证据包 |
| `/api/v1`、提交任务后轮询 | 后台媒体处理用持久任务号与真实阶段展示，不伪造百分比；本轮不引入SSE |
| 模型能力适配接口 | 视频理解、带时间码转写、旁白分别有接口；统一超时、有限重试、费用记录及输出语义验证，不把供应商返回直接当有效编辑清单 |
| Git及忽略规则 | 工具包已是仓库；不提交或丢弃现有未提交文件。应用密钥、依赖与媒体数据保持忽略 |

环境实测：Python3.12.16位于 `/opt/homebrew/bin/python3.12`，默认python3为3.9.6，不能用来创建本产品环境；Node24.22.0、npm11.19.1、Git可用。尚未安装FFmpeg/ffprobe，阶段2按本机条件安装并确认功能。8765被其他进程使用，不触碰；本产品建议127.0.0.1:8788，当前未观察到监听，实际绑定需本机执行权限，启动时再核验。

## 4. 偏离或暂缓的默认方案

- 正式Web默认采用Next.js/TypeScript/Tailwind，延至阶段3；阶段2的HTML只用于验收，不把临时页面当正式网页交付。
- 暂不引入Redis/Celery：首轮本机单用户、单worker，SQLite记录持久状态即可；出现多实例、经常并发超过5个长任务或实测恢复需求不再适配时再调整，不能只依赖FastAPI BackgroundTasks保存长任务。
- 暂不建立云对象存储、监控SLS、订阅套餐或平台账号；媒体保存在本机。CloudBase上线兼容与真实视频资源费用在阶段4核实，免费意向不代表免费额度足以渲染和分发。
- 不引入向量库、文档OCR、记忆框架、专业时间线编辑器或生成式视频模型；首轮以真实拍摄素材合成为主。
- 云模型候选沿用 [阶段0费用估算](阶段0-模型费用估算.md)：百炼北京 `qwen3-vl-plus`、`fun-asr-flash-2026-06-15`、`qwen3-tts-flash`。**这不是供应商准入通过**；国内留存与删除期限、账号下境内推理范围、Key及样片未全部就绪前，所有云模型默认禁用。不得自动换成境外服务、Coding Plan或更贵型号。
- 云能力禁用时，本地可验证登录、上传、素材预览、人工指定片段的确定性剪接/导出及任务恢复。页面明确提示“AI分析未启用”，不返回虚构故事方向或字幕。本地合成验证只证明媒体和业务链路，不证明AI综艺效果；不要求最终用户通过手写脚本替代产品主流程。

本阶段为设计审查，下表“已覆盖”指方案覆盖，全部运行效果都须阶段2实测。

| 底线 | 方案与验证要求 |
| --- | --- |
| 密钥与隐私 | 已覆盖：密钥仅本地忽略配置；云请求默认deny，Key不自动解锁；音频转写、配音、遥测和异常上报也受外发限制；D7准入仍待核实 |

| 人工确认与预算 | 已覆盖：方向选择、导出版本、删除影响均有人工动作；3元/制作任务和30元/首批硬限额，重试与修改不另获额度；费用估计未知则停 |
| 上传安全 | 已覆盖：MP4/MOV外延+实际容器/可解码轨道；1–8段、总≤10分钟/≤1GB；流式落盘、安全内部命名、探测/转码限时限资源，不直接信任MIME |
| 用户隔离 | 已覆盖：节目、媒体读取（含Range）、任务、输出和删除均后端校验；不直接公开data目录；一个用户的ID不能读取另一个用户的文件 |
| 云资源费用 | 已覆盖：本阶段不开通；模型仅预算确定，准入未通过；新收费资源仍先报具体费用 |
| 保护已有内容 | 已覆盖：原视频不动，候选与已确认版分离；删除应用副本先确认派生影响；不删除现有功能或测试 |
| 验收真实性 | 已覆盖：正常服务不以mock作为默认模型；离线测试及独立8790演示明确使用固定测试结果，数据隔离、醒目标注非AI，不计入真实冒烟。无真实验证时完整阶段待验 |

测试规划：权限越权与CSRF、上传伪装/上限、引用越界、版本确认失效、幂等/重复任务、预算越限/未知费用、重启恢复、FFmpeg真实合成与可解码输出。云适配器用受控假响应验证超时、失败、结构错误与重试；真实模型冒烟通过后由脚本自动记录，不手写记录。
