# 实施分批建议

日期：2026-11-06。用途：阶段0确认交付优先级，并为阶段1路线图提供输入；这不是已完成的技术适配声明或开发成果。

## 第一件可使用的成果

先完成已确认的单人核心链路：上传1–8段获授权视频 → 分析原片及声音来源 → AI提出有依据的方向 → 用户选择 → 生成带简单综艺包装的初版 → 核对并导出≤90秒、720p成片。

第一轮使用临时验收界面即可，正式手机/电脑网页在阶段3实现。临时界面不承诺保留为正式产品，不提前铺正式前端；若要保留，须在阶段1明确并按正式前端标准验收。

## 建议批次与需求追溯

| 批次建议 | 成果 | 覆盖的需求与验收 |
| --- | --- | --- |
| 后端2-1：单人核心出片 | 登录与归属、一期创建、上传校验、来源索引、方向确认、初版预览/导出、基础纠错、持久任务和旧版保护；临时验收入口 | FR01单人部分、FR02–FR05基础、FR09、FR10、FR12本地规则、FR13；AC01、AC03–AC13中适用部分、AC23–AC27、AC31–AC33的本地范围 |
| 后端2-2：朋友供材与真实采访 | 受限供材邀请、语音/视频采访、本人表达确认与发起人采用分离、异议及撤回依赖 | FR01多人部分、FR06–FR08、FR13扩展；AC02、AC13–AC21、AC24、AC27–AC28、AC31–AC33的多人范围 |
| 后端2-3：受控分享 | 固定版本分享、可见范围、关闭与失效、受限内容不再对外获取；线上生命周期规则另定 | FR11、FR12线上边界、FR08/FR13分享依赖；AC19–AC22、AC26–AC33 |
| 正式前端3：手机和电脑网页 | 在已验证接口上完成正式创建、选方向、制作进度、预览纠错、采访及分享体验 | 已纳入FR的界面与真实端到端验证；具体子阶段在阶段1规划 |
| 上线4：可选 | 另核实云端视频计算、存储/流量费用、账号隔离和恢复能力 | 上线手册验收；免费套餐意向不代表视频资源一定够用 |

FR14跨活动作品库为P1候选；AC34/AC35暂不计为本期必须通过，也不伪报通过。后端各批的精确AC拆分在对应阶段开发文档中写明，不以“部分适用”跳过完整产品承诺。

## 现在可推进与仍受限制的工作

| 工作 | 条件 |
| --- | --- |
| 需求核对、批次建议、阶段1技术适配 | 不发送素材、不花费模型费用；通过当前阶段闸门后继续 |
| 本地工程、上传、权限、状态、剪辑合成和mock测试 | 阶段1方案及批次确认后，在当前获准子阶段内实现 |
| 真实模型调用与真实素材外发 | 先核实服务留存/删除期限、境内推理；实际Key与获授权样片就绪；预算守卫生效 |
| 后端子阶段验收通过 | mock及真实冒烟等适用项均有证据，用户验收；无Key/无真实冒烟仍为待验 |
| 付费云资源、对外消息与公开部署 | 按已有授权范围分别处理，交接包本身不扩权 |

不把本地手工编辑清单、测试固定响应或教学参考循环标成AI导演已验证。技术可运行、真实内容质量和用户认可分别提供证据。
