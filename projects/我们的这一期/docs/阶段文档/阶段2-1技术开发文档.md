## 3. 输入、输出与媒体限制

输入1–8个MP4/MOV，合计≤1GB、≤600秒；技术边界为最长边≤4096、帧率≤60。校验实际容器、轨道及样本解码，选段渲染时完整解码；样本通过不能宣称整段原片无损。

输出最多90秒、横或竖720p、30fps；画幅以首段主体比例决定，等比例缩放及黑边，不裁主体。无音轨素材补静音。标准有声包装先安排≤60秒素材，旁白采用≤30秒独立片头；真人片段原声不叠加旁白，拼接时保留既有真人AAC音轨。最终总时长由实际成片再次检查。轻包装或原声模式不使用旁白，用户可另存空旁白版本；不克隆真人声纹、不伪造本人原话。

## 4. 实现组成

Python3.12、FastAPI、Pydantic、SQLAlchemy/Alembic、SQLite WAL、FFmpeg/ffprobe，配合单worker持久队列。临时HTML提供完整的证据核对与版本操作，不引入Redis或云资源。

| 模块 | 当前实现 |
| --- | --- |
| `services/media.py` | 容器/轨道校验、真实剪接、花字图层、720p成片 |
| `services/vision.py` | 本地稀疏抽帧、仅内存JPEG/Base64、北京接口适配、采样覆盖与待核对观察 |
| `services/speech.py` | 本地抽音/分块、ASR与TTS适配、结构/时间戳/费用校验 |
| `services/director.py` | 已核对来源证据到方向提案；校验素材标识与时间区间 |
| `services/pipeline.py` | 分析、证据检查点、方向、旁白的持久编排，调用前预留与权限复核 |
| `services/packaging.py` | 将已确认文案音频作为独立片头，与真人原声片段拼接 |
| `worker.py` | 串行领取任务，成功/失败回写，渲染前后重验来源 |
| `services/cleanup.py`、请求体限制中间件 | 持久删除重试；multipart解析前限制声明与实际接收大小 |

以上已有工程实现及离线验证，不再列为“尚未实现”；真实供应商兼容性和内容效果仍待验证。

## 5. 数据、原子检查点与恢复

Episode、Asset、Version、Job、Session、Budget、Audit、ModelCall保存在SQLite，业务记录含owner_id。素材和输出只使用应用UUID路径。证据保存修订号、确认修订号和来源集合；方向、版本绑定具体证据修订。修改生成新版本，旧确认版不原地覆盖。

任务先持久化再执行，发送前持久预留费用并验证任务、来源和许可；视觉请求另绑定材料摘要。**成功模型结果检查点与费用结算状态在同一数据库事务提交**，避免已付费结果丢失后被无意重复调用。将检查点发布到当前节目时仍复核来源与修订。ASR失败后可保留成功视觉结果；已知费用的失败可从检查点重试。

服务重启将running标记为中断失败，queued可继续；费用未知或发送后结果不明保持占用，不自动重发。页签断开不取消任务，不伪造进度。更新素材、证据、撤回来源会使依赖方向和版本受限；原文件仍存在不代表允许预览或导出。

## 6. API契约与人工动作

接口位于 `/api/v1`，业务及媒体都检查Cookie归属，修改需X-CSRF-Token并校验来源。统一错误为 `{"error":{"code":"…","message":"…"}}`；完整请求、响应可查看 `/openapi.json` 和 `/docs`。

| 接口 | 用途与前置条件 |
| --- | --- |
| GET status；POST auth/login；GET auth/me；POST auth/logout | 运行状态、邀请码会话 |
| GET/POST episodes；GET episodes/{id} | 创建与详情，含证据修订、方向、任务、版本、预算 |
| POST episodes/{id}/assets；GET assets/{id}/media | 上传校验与有权原片预览 |
| POST episodes/{id}/analysis | 分析当前素材；正常入口需真实云准入，演示仅测试数据 |
| PUT episodes/{id}/evidence | 带revision提交原有证据的文字/时间修订或移除，并明确confirmed；拒绝伪造来源 |
| POST episodes/{id}/directions | 至少一条已核对证据，且确认号对应当前修订 |
| POST episodes/{id}/direction | 选择方向、依据修订和包装，创建编辑草案 |
| POST episodes/{id}/versions | 新建或基于base_version_id另存，含选段、包装和≤120字旁白草案 |
| POST versions/{id}/narration | confirm_text明确确认此版文案及系统音色后入队；不原地改写文案 |
| POST versions/{id}/render；GET jobs/{id} | 非空旁白须先就绪；持久渲染与真实任务状态 |
| POST jobs/{id}/retry | 失败AI步骤重试；费用未知时后端拒绝 |
| GET versions/{id}/media；POST versions/{id}/confirm；GET versions/{id}/export | 预览、人工确认具体版本后导出 |
| GET assets/{id}/impact；DELETE assets/{id}?confirm=true | 查看派生影响并删除应用副本 |

人工确认依次包括证据核对、方向选择、旁白文案与系统音色、最终具体版本、删除影响。确认证据记录用户判断，不自动证明模型描述真实。UI轮询保留未保存编辑，修订冲突要求重新载入核对；动态文本用textContent/value呈现，不插入模型HTML。

## 7. 模型边界与后续真实验证

视觉只检查每个不超过15秒分段的中点帧，最多48帧；返回来源ID、抽帧定位时间、待核对观察、不确定项及采样缺口。不能把稀疏图像当连续动作、原声理解或人物关系判断。模型观察固定unverified，用户回看后才进入已确认导演证据。

ASR原声转写适配已实现，**非流式接口返回与时间戳仍须真实服务验证**；离线结构样本和官方字幕均不能冒充识别成功。TTS只读用户确认的文案，使用系统音色，不克隆真人声音；演示中的提示音更不能标为真实旁白。真实旁白自然度、片头效果和导演选片能力仍待样例打分。

## 8. 云端准入、预算与记录

按用户安排，上线前再接入阿里云候选服务。本轮不调用、不收费、不提交工单；供应商留存及删除期限、实际境内处理范围的既定要求未被取消。真实运行必须满足三个云开关、地址/型号白名单、有效Key及持久预算许可，不能仅凭有Key解锁。

每制作任务最多3元、首批累计30元；视觉、转写、方向、旁白、修改和重试共用账本。无法确定上界就拒绝；未知费用保留预留，不能按零元结算后重试。演示不产生供应商费用，且测试结果持久标记为非真实调用。

未来由 `scripts/smoke.py` 在满足真实调用条件时自动记录链路、模型、用量、耗时、结构校验和重试，不含密钥或私人正文。当前没有条件就不造记录；mock、演示、合成媒体均不写成真实模型冒烟通过。

## 9. 安全、删除与清理边界

服务只绑定127.0.0.1。正常邀请码在忽略的 `backend/.env`，随机会话只通过HttpOnly/SameSite Cookie保存，数据库存摘要；权限检查在后端。FFmpeg使用参数数组、shell=False、协议白名单和超时/线程限制，拒绝路径穿越、伪装文件与资源超限。

删除前显示影响；先持久撤销访问，再物理清理。deleted/restricted及任务产物登记作为清理依据，物理失败返回受控503，可重复DELETE或重启继续；不删除外部源片和未标记内容。抽音、渲染工作目录和WAV/MP4输出在创建前写入任务登记，启动取得单worker锁并恢复任务后，仅回收登记的废弃产物。成功版本、已付费TTS检查点和无关运行任务保留；不通过扫描目录猜测文件归属。
