## 结论

**公开资料不足以确认北京普通模型API输入、输出及相关副本的具体保留和删除期限。**不能把“30天可查询”“48小时临时文件清理”或“未开启推理日志”推导为全部数据到期删除。当前继续禁止外发真实素材。

## 分项核查

| 对象 | 官方能够确认的内容 | 不能据此确认的内容 |
| --- | --- | --- |
| 普通模型/应用调用数据 | 国内隐私页说明会存储调用数据，不用于模型训练 | 没有给出具体天数；不代表调用后即删 |
| 客户业务数据、对话与备份 | 协议6.2.4–6.2.7规定支持删除处置、对话按必要最短时间保留，备份可能延后清除，服务终止缓冲期另见产品说明 | 未提供本项目API内容的固定期限、单请求删除入口和备份清除时限 |
| 平台审计日志 | 默认开启，含调用标识、时间、用量等，不含Prompt/Response；最长查询范围30天 | 查询范围不是存储/物理删除期限 |
| 自有SLS推理日志 | 默认关闭；主动开启会投递完整Prompt/Response；关闭后停止后续投递 | 不证明供应商其他数据不留存，不会自动删除已有SLS记录 |
| 百炼临时上传文件 | 文件48小时后自动清理；非生产推荐路径 | 只覆盖临时文件，不覆盖同次调用的处理数据、安全记录与备份 |
| 国际站ZDR | 官方明确有网站、客户与非中国内地区域的适用范围 | 不能直接套用于北京国内服务 |
