# 阶段2-1：语音接口核查与离线适配

核查日期：2026-11-06。只查阅官方资料、实现本地代码并运行离线测试；未读取本地密钥配置、开通云资源、发送素材或调用真实模型。供应商留存及境内处理准入仍未完成，三个云开关默认关闭，配置Key不会自动解锁。

## 已核实的接口

| 环节 | 官方事实 | 本次落点 |
| --- | --- | --- |
| ASR | 精确型号为 `fun-asr-flash-2026-06-15`；HTTP支持Base64 Data URI；单文件最长5分钟、最大2GB；没有说话人分离能力 | 固定此型号，本机先抽成16kHz、单声道、16位PCM WAV，每块默认30秒，直接Base64请求，不创建OSS或公开上传URL |
| 时间戳 | `output.text`为累计全文，`output.sentence`为当前句；句与词的起止时间单位为毫秒；最终句及稳定词分别由 `sentence_end`、`fixed` 标识 | 校验稳定性、顺序、边界和全文覆盖，恢复到原素材绝对秒；缺失时间戳或与全文不一致就报错，不按文本长度猜时间 |
| TTS | `qwen3-tts-flash` 单次最大输入600字符，支持系统音色；本次固定 `Cherry` 和中文 | 只合成人工确认的旁白，不复刻声音；输出必须是完整可解码PCM/WAV且不超过30秒，否则拒绝，不自动裁切 |
| 下载 | 完整音频URL有效24小时；Base64 PCM示例为24kHz、16位、单声道 | 优先处理Base64；仅允许北京结果域名 `dashscope-result-bj.oss-cn-beijing.aliyuncs.com`，实际下载一律HTTPS且不跟随重定向，不发送API鉴权头 |

来源：[Fun-ASR-Flash HTTP协议](https://help.aliyun.com/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)、[语音输入规格](https://help.aliyun.com/zh/model-studio/asr-model)、[Qwen-TTS接口及PCM示例](https://help.aliyun.com/zh/model-studio/qwen-tts-api)。

北京原生请求路径固定为 `https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`。ASR文档已推荐迁移到业务空间专属的北京域名，并明确列出原域名；本实现沿用已配置的北京域名，不自动迁移、不拼接任意业务空间或用户URL。若原端点后续不可用，应重新核查配置后修改白名单。

TTS官方样例给出的结果URL使用HTTP。本实现仅对上述单一已核实OSS主机升级到HTTPS，保留路径与签名查询参数；HTTPS不可用就失败，不回退HTTP。URL到期不是内容或备份已删除的证明，Base64输入也不代表供应商零留存。

## 计费与预留

[官方价格页](https://help.aliyun.com/zh/model-studio/model-pricing)显示，北京ASR按音频秒数收费，每秒0.00022元，输出不另计；TTS每万计费字符0.8元。**汉字按2个计费字符，其他字符按1个计算**，不能用中文正文的字数直接当计费字符数。

- `asr_reservation_yuan(chunks)`：逐块实际WAV时长向上取整到秒，再乘0.00022元和最多2次尝试。例如20块各30秒，预留0.264元；多素材尾块按实际分块重新计算。
- `tts_reservation_yuan(text)`：按上述汉字计数规则计算，再乘0.00008元和最多2次尝试。例如600个纯汉字预留0.192元；这是费用上限示例，不代表600字能在30秒内播完。
- 上例与导演适配预留1.82元合计2.276元，尚未含视觉分析、后续修改与重复任务；整条任务仍须通过持久账本检查3元/任务、30元/首批上限。
- 结算只依据供应商返回的 `usage.duration` / `usage.characters`。缺失或不合法时记 `cost_yuan=None`；任一连接重试的前次费用不明，即使后次成功也保持未知。超时不盲目重试，连接失败最多重试一次。
- 已合成但下载、解码或时长校验失败时，保留已知合成费用；不能因本地没有可用文件把计费归零。

## 集成接口

维护源为 `backend/app/services/speech.py`，测试为 `backend/tests/test_speech.py`。

```python
chunks = extract_audio_chunks(source_path, controlled_output_dir, asset_id)
required = asr_reservation_yuan(chunks)
# 上层先按required创建持久预算预留，再把记录ID传入。
speech = CloudSpeech(config, budget_check=check_persisted_reservation)
transcription = await speech.transcribe(chunks, reservation=reservation_id)
# result: [{asset_id, start, end, text}]，start/end为原素材绝对秒。

required = tts_reservation_yuan(confirmed_narration)
voice = await speech.synthesize(confirmed_narration, new_wav_path,
                                reservation=another_reservation_id)
# result: {path, duration}。输出原子发布，不覆盖已有文件。
```

`budget_check(ID)`必须返回严格布尔值True，负责核实预留记录归属、有效状态及足额金额。ASR与TTS使用共享北京Key，但型号在语音适配器内固定，不会随导演的 `MODEL_NAME` 切换。上层负责用户权限、旁白确认、账本结算和任务持久化，适配器不替用户批准外发或付费。

两类结果都携带 `usage`：`cost_yuan/input_tokens/output_tokens/model/retries/request_id`，语音不适用的token字段为None，另有 `seconds` 或 `characters`。失败通过 `SpeechError.usage`保留费用；ASR多块调用还保留逐请求用量记录，不包含转写正文或音频URL。

## 验证与待验

独立测试48/48通过。覆盖默认禁用、Key不能解锁、预算前置、客户端初始化失败、Base64请求、时间戳及全文覆盖、未知费用、有限重试、恶意下载URL、重定向、超长/截断音频、输出不覆盖；另以本地合成视频实测FFmpeg提取、分块偏移与源文件不变。云响应全部由MockTransport提供，不能视为真实模型冒烟。

仍须在既定准入条件满足后核实：账号下原北京端点及型号可用性、真实多句ASR的完整词级时间戳、多人重叠语音与方言质量、TTS返回数据及HTTPS结果下载、30秒旁白可用字数和真实计费。非流式ASR若只返回最后一句时间戳，本实现会明确报 `INCOMPLETE_TIMESTAMPS`；需要据真实证据适配流式完整句收集，不能把遗漏内容伪装为完整转写。
