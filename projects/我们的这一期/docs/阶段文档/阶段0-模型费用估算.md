## 费用计算

以已确认首轮上限10分钟音轨、≤90秒成片为计算场景。下列 Token 数是用于比较预算的假设，不是对10分钟视频实际消耗的预测；抽帧、图像尺寸、文本长度都会改变用量。

| 项目 | 假设 | 模型费（元） |
| --- | --- | ---: |
| 原片转写 | 600秒 × 0.00022 | 0.132 |
| 故事与编辑清单 | 20K输入 + 4K输出 Token | 0.060 |
| 旁白 | 600计费字符 × 0.8/10000 | 0.048 |
| 旁白转写对齐 | 90秒 × 0.00022 | 0.0198 |
| 视频理解场景A | 20K输入 + 4K输出 Token | 0.060 |
| 视频理解场景B | 120K输入 + 8K输出 Token | 0.300 |
| 视频理解场景C | 240K输入 + 8K输出 Token | 0.960 |

固定部分加视频理解A/B/C，分别约 **0.32 / 0.56 / 1.22元/次**。不包含重试、重新生成、云存储/传输/云端渲染。600字符只是预算假设，不保证配音一定为90秒；实际合成后应测时长和原声覆盖。

1. 北京入口不自动等于境内推理。官方区分2026-10-13前的“中国内地”模型与此后默认“中国弹性区”模型，后者可能使用境外地域。上述较早型号有境内范围依据，实际账号开通时仍须核对；不得自动切换到全球或弹性区。[北京接入说明](https://help.aliyun.com/zh/model-studio/beijing-access-information)、[模型发布记录](https://help.aliyun.com/zh/model-studio/newly-released-models)。
2. 中国站隐私说明称不将用户数据用于模型训练，同时说明会存储调用产生的数据；该页未明确具体保留期限。不能承诺请求完成即删除，也不能把国际站的零留存政策套到北京。[国内隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)、[国际政策适用范围](https://www.alibabacloud.com/help/zh/model-studio/data-retention-policy)。用户已明确要求先核实保留与删除期限再发送素材，核实未完成，不发送真实素材；详见 [留存核查](阶段0-模型数据留存核查.md)。
3. 优先评估直接 Base64 ASR，以免单独创建用户OSS资源；此方式仍受供应商调用数据政策约束。备选 filetrans 的免费临时上传会保留文件至48小时自动清理，官方不建议用于生产；不是“零留存”。本轮不启用此备选。[临时上传规则](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)。
4. 应用本地保留到主动删除的约定只覆盖本应用副本；删除本地副本不能表示供应商请求记录也已删除。若用户要求确定的云端删除时限，应先取得供应商明确说明或换用符合条件的方案。
