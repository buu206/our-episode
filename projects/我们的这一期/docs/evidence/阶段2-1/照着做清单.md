## 3. 点击完整演示流程

1. 打开8790，确认页面醒目标明演示、非真实AI及提示音非旁白。输入公开测试码 `demo`，点击进入工作台。
2. 左侧新建一期，选择上面的三个文件，点击“上传所选视频”。看到三段素材及各自时长，点击“预览”检查原片。外部源文件不会被改写。
3. 点击素材区“生成固定演示占位”，阅读说明后确认仅生成演示占位。等待任务完成；出现的是固定测试观察与转写，不是实际AI识别。
4. 在证据区点“回看来源”，核对播放器定位；修改一条证据的文字或时间，移除不可靠内容。点击“已知是占位数据，确认演示步骤”，阅读提示后点“已知为占位，确认演示”。这只确认流程，不表示占位内容真实。
5. 点击“取得固定演示方向”。等待测试方向出现，查看标题、说明及来源引用。选择“演示包装 · 提示音片头 + 原声片段”，再点“选此方向，生成编辑草案”；草案应载入编辑区，可调整起止时间、花字和旁白文字。修改后点击“保存新版本”，旧版应保留。
6. 若保留旁白草案，在版本区点击“确认演示文案并生成提示音”，核对文字和提示后点“确认生成非人声提示音”。此次得到的是**合成提示音，不是人声配音**。任务完成后音频应标为就绪；未就绪前渲染按钮应受限。也可选择轻包装/原声，或“另存为无提示音版本”，保存后直接本地合成。
7. 点击“渲染此版本”，等待变为“可预览”。完整播放，检查选段顺序、画面、花字、提示音片头和真人原声。片头独立，不在真人原声上叠提示音；总时长不超过90秒。
8. 点“已预览，确认此版本”，确认后点“导出已确认MP4”，在浏览器下载列表查看文件。将第2节的完整署名说明随导出文件保留。
9. 点“载入选段继续修改”，改一个片段后另存。应产生新版本，原确认版仍保留；任何素材或证据修订导致的限制仍以服务端当前状态为准。

失败时先读任务的实际错误。AI步骤可点击重试，但费用未知的真实调用将由后端拒绝，不能靠重试刷新预算。当前演示本身不产生真实模型费用。

## 4. 核对正常手动入口

打开8788，应看到云模型未启用。用本地编辑器打开产品 `backend/.env`，将 `APP_INVITE_CODE=` 后的内容填入页面；不要把值贴到聊天、日志或截图中。

登录后新建一期、上传获授权素材，点“＋选段”，填写起止秒数和可选花字。选择轻包装或原声、保持旁白为空，保存新版本→渲染→完整预览→确认→导出。此链路使用真实FFmpeg，不调用模型。首轮最多8段、总10分钟/1GB；当前解码上限为4K边长、60fps；输出720p、最长90秒。

删除不是必做验收步骤。如确需删除应用副本，先点“删除”查看关联影响再确认；关联版本将受限，外部原片不删除。物理清理失败会提示未完成，可重试删除或重启继续处理。
