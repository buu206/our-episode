# 阶段2-2本机验收

打开 http://127.0.0.1:8790，使用公开演示登录码 `demo`。服务未启动时，在工具包根目录执行 `bash projects/我们的这一期/scripts/run-demo.sh`。本轮不需要阿里云、Key或充值。

## 1. 发起人创建邀请

选择“2-2协作验收 · 非人物技术样片”，点击“朋友供材与采访”。填写朋友称呼，选择“补一段事后采访”，指定本期视频1–4秒，填写一个问题并点“创建邀请”。点击“在新标签打开朋友入口”。邀请只在本机生效，不对外发送；创建后明码只显示一次。

## 2. 朋友预览和提交

在朋友页填写称呼、勾选身份确认，点击“进入我的任务”。应只见授权的3秒上下文和自己的稿件。问题可以改写或跳过。

文件可选产品目录 `data/测试素材/2-2协作技术样片/` 下的 WAV 或 MP4；二者是无真人的技术信号，不是真实采访。选择对应文件类型、填写简短说明并“上传为我的草稿”。等预览就绪后完整播放。提交之前，发起人页刷新仍不显示草稿。

文字有误可展开“修改我的草稿文字”，无需重传。不要的未提交草稿可明确删除应用副本；撤回仅停止授权，仍保留文件并占配额。

勾选完整预览确认，点击“确认并提交给发起人”，再点“本人确认，提交”。发起人刷新后应看见稿件。

## 3. 修改后必须重新确认

发起人展开“提出改写或截短建议”，修改文字或时间，保存建议。该新修订应标为待本人核对，不能采用。朋友刷新，核对文字和具体原声区间，可接受或拒绝。接受后发起人才可“采用这个已确认修订”。

## 4. 采用与新成片

采用就绪后返回剪辑工作台，应新增标明“事后采访”的素材。点击“＋选段”，采访片段的时间和文字不可随意改写，但可以整体移除。与现场素材一起另存新版本，渲染、完整预览、确认，再导出。旧版不被新投稿自动替换。

## 5. 异议、撤回与关闭邀请

朋友在“表达异议与处理”选择自己的稿件、填写原因并提交。发起人刷新后，含争议内容的成片应受限，不能预览或导出；未涉及的版本不应被限制。可在新版本移除相关片段继续制作；只有提出者能确认自己的异议已解决，恢复后发起人仍需重新预览确认。

“撤回使用授权”会继续限制关联内容，不能靠恢复旧版绕过。关闭邀请后不能再新增投稿，已认领的人仍可管理已提交表达和异议。已下载到外部的副本不能自动收回。

## 身份检查说明

两个标签页便于同一人体验双方流程，但浏览器同时保存了发起人和朋友的两套会话。要手动核验身份隔离，请在另一个浏览器或无痕窗口打开朋友邀请，仅登录朋友身份：此时打开工作台不能读取发起人节目。多个朋友请分别使用独立浏览器会话；同一浏览器只能保持一个当前朋友身份。
