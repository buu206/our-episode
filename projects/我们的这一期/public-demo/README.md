# 在场公开交互演示

这是独立于真实服务的静态演示入口。复用产品品牌与首页配色，提供主题输入、方向选择、字幕/花字版式调整、声音/边框偏好、方案文本下载和固定导演功能介绍。

页面明确标注演示；人物为既有 AI 生成的虚构角色。不包含真实视频、数据库、邀请码、模型请求或实时 AI 对话，不把示意图当作成片。没有上传控件；输入仅保留在本页内存，刷新重置。CSP `connect-src 'none'` 禁止应用联网请求；浏览器仅加载同站静态文件，托管平台仍可能记录常规访问日志。

构建：在产品目录执行 `python3 scripts/build-public-demo.py`。使用已有前端 TypeScript 编译器，不安装额外依赖。产物在 `data/runtime/public-demo-site/`；发布只取该目录的白名单文件，不能上传整个产品目录。

Logo 来自用户提供的品牌文件，头像与字体来源见 `docs/设计参考/本轮资产来源.md`。发布保留 `assets/OFL.txt`。运行该页不代表真实制作服务上线。
